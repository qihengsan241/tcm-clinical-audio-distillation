# 数据架构

## 内容对象

| 对象 | 作用 | 必要关系 |
|---|---|---|
| session | 一次录音或跟诊活动 | 包含时间、来源、参与角色和内容地图 |
| case | 完整病例或病例片段 | 连接问诊、判断、处方、随访、教学单元 |
| teaching_unit | 老师传授的思考方法 | 连接例子、方药、误区和验证方法 |
| teacher_wiki | 可跨病例复用的老师经验 | 必须回链来源病例或原音时间 |
| formula_reasoning | 某病例中的方药及使用理由 | 必须标明处方角色和核方状态 |
| follow_up | 服药后的变化和不良反应 | 回链原病例与原判断 |
| care_advice | 饮食、作息、运动、针灸等调护 | 与医疗处方分开 |
| ai_explanation | AI补充的医理 | 列证据、缺口、置信度和验证方法 |
| verification_item | 待回听或询问老师的问题 | 包含时间点和核对目的 |

## Session

- 标题、日期、地点或场景；
- 原始音频路径、时长、转写版本；
- 录音性质：门诊跟诊、师承交流、病例讨论、复盘；
- 内容地图：时间段、主题、涉及病例；
- 隐私处理状态；
- 总体听写质量及高风险片段。

## Case

### 基本事实

- 病例编号和原音时间；
- 就诊性质：初诊、复诊、病例回顾、教学举例、本人咨询；
- 年龄、性别、体重；未提及时明确写未知；
- 主诉、病程、既往史、用药史、过敏史；
- 四诊、体征、检验和影像；
- 危险信号及缺失信息。

### 问诊路径

- 老师问了什么；
- 每个问题想获得什么关键信息；
- 不同答案可能把判断引向哪里；
- 提问后老师的判断是否发生变化。

### 辨证与治法

- 中医病名或疾病阶段；
- 证候、核心病机、次要病机、病位；
- 寒热虚实、程度与缓急；
- 每条判断对应的症状、舌脉、病程或检查证据；
- 矛盾信息与尚未排除的解释；
- 主要治法、兼顾治法和先后次序。

### 方药

- 方名：原方、合方、自拟方或未知；
- 处方角色：实际开具、旧方回顾、条件性举例、教学讨论、无法判断；
- 组成、剂量、加减、煎服法、频次、疗程；
- 老师为何选此方；
- 方证与核心病机的对应；
- 关键药物或药对的作用；
- 加减原因；
- 剂量或比例与病情程度、体质的关系；
- 老师明确比较过的备选方及未选原因；
- 预期观察点、不良反应和监测点；
- 原音置信度；
- 核方状态：未核、已回听、已核处方笺、已向老师确认。

### 疗效验证

- 主症、次症、舌脉和客观指标变化；
- 起效时间及信息来源；
- 不良反应、停药、换方或续方原因；
- 哪些变化支持老师原判断；
- 哪些问题仍无法解释。

## Teaching unit

使用以下字段保存“老师怎样教会学生思考”：

- 教学主题；
- 老师的核心命题；
- 触发这段讲解的问题或病例；
- 使用的病例、方剂、药物或经典条文；
- 从信息到判断的推理链；
- 病情程度和患者条件如何改变用药力度；
- 老师指出的常见误区；
- 用疗效验证判断的方法；
- 适用边界；
- 关联病例、Wiki 和原音时间；
- 听写置信度。

常见教学结构为：

> 提出总原则 → 用病例或方剂举例 → 连接经典与病机 → 解释用药力度 → 指出误区 → 说明如何验证

## Teacher Wiki

- 一句话经验；
- 老师的原始解释；
- 知识连接链；
- 适用条件；
- 不适用或慎用条件；
- 来源病例和原音时间；
- 已验证病例数；
- 与其他经验的关系；
- 核实状态。

不要把同一段录音中的重复转述计算成多次临床验证。

## Formula reasoning

每首方至少尝试建立五层连接：

1. 症状层：针对哪些具体表现；
2. 方证层：这些表现为何构成老师所说的方证；
3. 病机层：怎样处理核心病机；
4. 配伍层：关键药物怎样协同、制约或保护正气；
5. 程度层：为何采用当前剂量、比例、服法和疗程。

如果原音没有某一层，标记缺失并生成待追问项。

## AI explanation

- AI提出的解释；
- 所属理论框架；
- 依据的录音事实；
- 能解释与不能解释的内容；
- 仍需哪些问诊、舌脉或检查；
- 与老师观点的关系：支持、补充、可能不同、老师未谈及；
- 置信度；
- 安全边界和验证方式。
